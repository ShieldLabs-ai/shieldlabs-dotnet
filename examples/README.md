# Examples

| Example | Framework | Shows |
|---|---|---|
| [`MinimalApi`](MinimalApi) | ASP.NET Core minimal API (.NET 8) | `POST /signup` reads the verdict for a request ID and applies a policy; `POST /webhooks/shieldlabs` verifies and logs webhook deliveries |

The examples reference the SDK project in this repository. In your own app, install the package
instead: `dotnet add package ShieldLabs`.
